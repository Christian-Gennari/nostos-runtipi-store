# Nostos for Runtipi

Runtipi app store for [Nostos](https://github.com/Christian-Gennari/Nostos), a self-hosted home for your reading life: read EPUB, PDF and audiobooks, keep passages with their source, and write from them.

To install it, open **Settings → App Stores → Add App Store** in Runtipi (v4.0.0 or later) and add this repository's URL.

The package's source of truth is [`deploy/app-stores/runtipi/`](https://github.com/Christian-Gennari/Nostos/tree/main/deploy/app-stores/runtipi) in the Nostos repository. This repository is a copy so Runtipi can read it. Report problems in [Nostos issues](https://github.com/Christian-Gennari/Nostos/issues).
